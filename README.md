## Getting Started

### 1) Install dependencies
```bash
npm install
```

### 2) Run the development server
```bash
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:3000`).

### 3) Build for production
```bash
npm run build
npm run start
```

## Project Structure (high level)

- `src/app/` — Next.js pages/routes 
- `src/components/` — UI components and page sections
- `src/lib/data.ts` — Portfolio content (projects, timeline, skills, etc.)
- `public/` — Static assets (fonts, images, CV, certificates)
